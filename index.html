实事求是群众路线独立自主

科技霸权封锁下，研发团队能否突破核心技术？
角色随机分配 · 120道毛概题库 · 三轮抢答夺取行动点

游戏规则

一、背景设定

一场科技突围战。正方是专家和领袖组成的研发双核团队，反方是试图摧毁研发命脉的黑客。三个属性决定胜负：实事求是（数据与底层逻辑）、群众路线（开源生态与人才协作）、独立自主（核心专利与供应链安全）。每项属性在布署后有一个初始数值，之后每回合随推进和打击而变动。

二、胜负判定（结算时按以下顺序判断）

  1. 反方胜利：任意一个属性 < 0，研发命脉断裂，黑客立即获胜。
  2. 正方胜利：任意一个属性 > 10，核心技术突破，正方团队获胜。
  3. 若以上均不满足，游戏继续进入下一回合。

注意：属性不设上下限硬锁，允许在行动中超出 0~10 范围。结算时直接用实际数值与 0、10 比较。

三、信息隐藏机制（核心）

  • 只有主持人能看到具体数值。正方和反方在任何时候都无法直接看到属性点数。
  • 布署阶段：正方A和正方B各自秘密分配，互相不知道对方分配了什么。
  • 推进/打击阶段：当前操作的选手只看到自己的点数分配面板，看不到属性当前值。
  • 谈判阶段：主持人只口头通报各属性的状态等级（如"危急""正常""临门"），不公开具体数值和对应属性名。
  • 正方队友之间、正方与反方之间，只能通过公开谈判口头交流。不知道队友和对手干了什么，只能靠推测和博弈。
  • 黑客每回合有一次窥探机会：可选择一个属性查看其当前最新具体数值（在专家和领袖完成推进之后）。

四、角色介绍

  • 🛡️ 专家（正方）：防御型角色。基础推进 0 点。每回合必须选择一个防御属性——黑客本回合对该属性的伤害全部无效。抢答奖励可增加推进点。
  • ⭐ 领袖（正方）：进攻型角色。基础推进 2 点。无特殊技能，但稳定的推进力是团队突破的关键。抢答奖励可增加推进点。
  • 💀 黑客（反方）：进攻+情报角色。基础伤害 3 点。每回合攻击前可窥探任意一个属性的具体数值。单个属性最多投入 3 点伤害。抢答奖励可增加伤害点。

五、点数机制

  • 专家每回合推进点 = 0（基础）+ 抢答中"专家"获得的奖励次数。
  • 领袖每回合推进点 = 2（基础）+ 抢答中"领袖"获得的奖励次数。
  • 黑客每回合伤害点 = 3（基础）+ 抢答中"黑客"获得的奖励次数。
  • 奖励各自独立，不共享。
  • 专家推进和领袖推进先后结算，各自独立确认。确认后推进效果即时生效。

六、完整回合流程

  1. 秘密布署（仅开局一次）：正方A 和 正方B 各自秘密将 5 点分配到三个属性。双方分别操作，互相不可见。两人的分配相加成为三个属性的初始值。
  2. 毛概抢答（每回合3题）：主持人操作屏幕——屏幕显示题目和正确答案（仅主持人可见）。主持人读题，正方和反方口述抢答。主持人根据抢答结果点击对应按钮（正方答对 / 反方答对 / 无人答对），答对者在当回合获得 +1 行动点奖励。每回合依次进行 单选题 → 填空题 → 多选题。
  3. 公开谈判（30秒）：三名选手共同讨论。主持人只透露各状态的数量（如"2个危机、1个正常"），不透露哪个属性是什么状态。选手禁止透露具体数值。
  4. 专家行动：专家到屏幕前，选择防御属性，分配推进点（如有），确认后推进立即生效。
  5. 领袖行动：领袖到屏幕前，分配推进点，确认后推进立即生效。
  6. 黑客行动：黑客到屏幕前，可窥探一个属性的最新数值（此时专家和领袖的推进已生效），然后分配伤害点，确认后进入结算。
  7. 亮牌结算：主持人屏幕展示本回合所有推进和伤害明细，以及属性的最终变化。按胜负判定顺序检查是否有一方获胜。未分胜负则回到步骤2。

七、毛概题库

共 120 题，分为单选题（40题）、填空题（40题）、多选题（40题），覆盖毛泽东思想的全部核心知识板块（活的灵魂、新民主主义革命、武装斗争、统一战线、党的建设、矛盾分析、群众路线、独立自主等）。每回合三种题型各出一题，随机不重复抽取。

八、主持人操作说明

电脑全程由主持人控制。选手只在轮到自己的行动阶段到屏幕前操作面板，操作完成后立即离开。主持人负责：读题、判定抢答得分、主持谈判、引导行动顺序、结算公布结果。任何选手不得在非自己回合偷看屏幕。
